# Hello, Orbit.

A small workspace for your next big idea.

Open main.ts and press F5 to run it with Node.js 22.18 or later.
This sample has no dependencies to install.

## Make yourself at home

- Ctrl+S — save your work
- Ctrl+P — jump to a file
- Ctrl+Shift+P — find a command
- Ctrl+Shift+F — search the workspace
- Ctrl+D — select the next occurrence (multi-cursor)
- Alt+Click — add a cursor
- Ctrl+backslash — split the editor
- Ctrl+backtick — show or hide the terminal
- Ctrl+Space — completions
- F1 — type information at the cursor
- F12 — go to definition
- Shift+Alt+F — format a JavaScript or TypeScript document

Create a file using the explorer toolbar, or open your own folder.
Your starter workspace is a real folder on your computer.
